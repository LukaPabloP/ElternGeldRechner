# Elterngeld-Rechner

A calculator for Elterngeld, the German parental allowance. It walks parents through three steps (income, family details, result) and estimates the monthly allowance, including the sibling bonus and the supplement for multiple births.

**Live:** https://lukapablop.github.io/ElternGeldRechner/elterngeld.html

The site is in German because it is made for parents in Germany.

## Features

- Step by step form with a result page
- Calculation details shown alongside the result
- Summary page ("Elterngeld-Fahrplan") with the entered data and next steps
- Legal notice and privacy page

## Tech stack

Static HTML with React and Tailwind CSS loaded from a CDN. No build step and no backend.

## Run it locally

Open `elterngeld.html` in a browser.

## Disclaimer

The result is an estimate and not legal or financial advice. The binding calculation is done by the responsible Elterngeld office.
